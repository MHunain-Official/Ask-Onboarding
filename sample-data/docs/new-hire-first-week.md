# New Hire: First Week

## Day 1 (Monday)

- 09:30 Welcome session with people-ops in the main meeting room (or on video if remote).
- Collect your badge and laptop, or complete the laptop setup if it was shipped.
- Meet your manager and your onboarding buddy.

## Day 2

- Set up accounts: email, Slack, password manager, VPN.
- Read the handbook pages: Security Basics, Password Policy, Slack Norms.

## Day 3

- Start the security awareness course (due within 14 days).
- Engineers: clone the API repository and run the tests (see the Local Development page).

## Day 4

- Shadow a team meeting and a code review.
- Complete your benefits enrolment.

## Day 5

- 30-minute check-in with your manager. Agree on goals for the first 30, 60 and 90 days.
- Give feedback on onboarding in the survey at https://people.acme-onboarding.example/survey.

## Who to ask

Your onboarding buddy for everyday questions, people-ops@acme-onboarding.example for HR, and #help-it for technology.
