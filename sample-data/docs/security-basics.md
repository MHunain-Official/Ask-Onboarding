# Security Basics

Every employee is part of the security team. This page lists what is required from day one.

## Required for everyone

- Complete the security awareness course within **14 days** of your start date.
- Use multi-factor authentication (MFA) on every company account.
- Keep your operating system and browser auto-updates turned on.
- Use only the company password manager (see the Password Policy).

## Phishing

If you receive a suspicious email, do not click anything. Use the **Report Phish** button in the mail client or forward it to phishing@acme-onboarding.example. Security reviews every report within 1 business day.

## Data classification

| Level | Examples | Rule |
|---|---|---|
| Public | Marketing pages | Share freely |
| Internal | Wiki, handbook | Employees only |
| Confidential | Customer data, contracts | Need-to-know, encrypted storage |
| Restricted | Salary data, keys | Named people only |

## Reporting incidents

Email security@acme-onboarding.example or call the security hotline at +1-555-0142 (24/7). Report first, investigate later. Nobody is punished for reporting a mistake quickly.

## Removable media

USB storage devices are blocked by policy. Ask IT if you need an exception.
