# Password Policy

## Requirements

- Minimum length: **14 characters**.
- Do not reuse any of your last **10** passwords.
- Passwords expire every **180 days** unless you use a hardware security key.
- A password may never contain your name, your email or the word "acme".

## Password manager

All work passwords must be generated and stored in the company password manager at https://vault.acme-onboarding.example. Browser-saved passwords are not allowed for work accounts.

## Multi-factor authentication

MFA is mandatory. Preferred methods, in order: hardware security key, authenticator app, SMS (only as a last resort).

## Lockout and reset

After **5** failed sign-in attempts your account is locked for 15 minutes. Reset at https://it.acme-onboarding.example/reset or ask the help desk.

## Never

- Share a password with anyone, including IT. IT will never ask for your password.
- Write a password down, send it over Slack or email, or put it in a code repository.
- Use a work password on a personal site.
